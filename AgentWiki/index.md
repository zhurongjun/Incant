# 项目知识地图

本索引用于导航。具体规则保存在相应领域的叶子文档中。

## 读取方法

1. 先理解任务，结合相关代码、测试和配置确定需要的知识。
2. 只进入当前任务相关的分支；有 `index.md` 时遵循其导航，没有索引时按文件名和搜索结果定位。
3. 已知目标文档时可以直接读取，但仍遵循该领域的基础规则与读取流程。
4. 按需读取相关章节，信息足够后停止扩展范围，不为完整性遍历整个知识库。
5. 读取相关知识时简短说明主题，例如“正在阅读 C# 代码组织规则”；不为普通读取反复请求确认。
