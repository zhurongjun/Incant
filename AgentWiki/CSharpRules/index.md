# C# 规则索引

本领域按基础原则、代码组织与具体书写划分 C# 规则。

## 开发与审查流程

1. C# 开发前先读取基础规则，结合变更范围进入代码组织或书写规则；测试工作同时进入测试领域。
2. 实现时按需读取相关章节，不要求每次完整读取全部 C# 文档。
3. 完成后按基础规则的退出验收流程，分项审查完整差异；不能以按需读取为由漏掉适用规则。

## 文件索引

- [基础规则](BasicRules.md)：适用范围、共同原则、特殊情况、编码前检查和退出验收。
  C# 开发及审查前读取。
- [代码组织规则](CodeOrganizationRules.md)：文件、命名空间以及类型与成员的组织。
  新增或调整文件、类型、成员及代码结构时读取。
- [代码书写规则](CodeWritingRules.md)：格式、命名、类型使用、表达式、控制流、异常及文档注释。
  编写、修改或审查具体 C# 代码时按涉及的章节读取。
- [测试规则](../Testing/index.md)：单元测试设计与执行。
  变更涉及测试时读取。
